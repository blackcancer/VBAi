# Procédures à valeurs — matrice complète avant exécution

- Native : nom/PID du processus, HWND réellement détenu, IUnknown valides/différents/libérés, classeur absent/ambigu/non sauvegardé, chemin nul/relatif/divergent, catalogue borné.
- Dispatch : cible owned uniquement, chemin relu, qualification apostrophes, paramètres tableaux/scalaires transmis sans exécuter Excel, retour et nombre exact de livraisons.
- Préparation : mode, module standard unique, signature/source/body/SHA, toutes formes de chemin rejetées, changement pendant résolution (mode/path/source/empty).
- File : contexte absent, null, capture des noms, état Delivering, Post rejeté, identité reformatée, expiration normale et mixte appels Immediate/valeurs.
- Retour : échec/incertitude, retour normalisé/rejeté, aucune réexécution à la lecture.
- Aucun Office démarré : Native Run est un dispatch géré ; la preuve réelle Excel demeure distincte.
