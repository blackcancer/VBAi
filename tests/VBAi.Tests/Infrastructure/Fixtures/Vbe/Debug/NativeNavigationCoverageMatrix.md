# Native navigation contract matrix

Owned UIA providers exercise project trees, toolbox tabs/buttons/items and macro lists.
Cases cover root absence, inaccessible enumeration, hidden/wrong/ambiguous surfaces,
foreign toolbox owners, child/top-level deduplication, inaccessible MSAA fallback,
empty providers, bounded node count, duplicate runtime identities, parent identities,
optional and failing patterns, expired tokens, selection, expansion and collapse.
Only provider-owned windows receive semantic pattern actions. No Office application,
keyboard shortcut, mouse coordinate or user project is used by this matrix.
