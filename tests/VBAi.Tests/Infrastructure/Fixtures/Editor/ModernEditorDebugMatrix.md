# Débogage de l’éditeur — matrice avant exécution

- Observation : absent, occupé, module géré, même mode/document, exécution, pause propre, brouillon, conflit.
- Révisions : commande absente/gérée/occupée, version périmée, capture, synchronisation, reformatage (autorisé pour compilation seulement).
- Compilation : modes, diagnostic préexistant, erreur de commande, observation nulle/blanche, sélection étrangère, diagnostic exact et révélation ; aucun soulignement de brouillon/conflit/source divergente.
- Navigation : instruction suivante dans le bon composant ; pointeur étranger refusé ; marquage de chaque document.
- Inventaire : contrôle désactivé, légende sans rapport, pagination 200/2000, commande absente, action inconnue, breakpoint et trois actions de pas à pas.
- Cycle : busy restauré après succès/erreur ; signaux de fin de compilation ; frontières renderer/dialogue substituées, commandes VBIDE simulées, aucun Office ni macro exécutée.
